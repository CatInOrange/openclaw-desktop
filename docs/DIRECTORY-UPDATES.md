# 免安装目录版更新（v0.4.7）

## 首次切换

v0.4.6 的旧目录版没有固定更新入口，不能通过新包远程修改它已经加载的代码。首次请从托盘退出旧版，完整解压 `OpenClaw-Desktop-0.4.7-win-x64-directory.zip` 到新的工具目录，再运行根目录 `OpenClaw.exe`。已有连接、Control UI 登录、音乐登录及桌宠设置仍保存在同一用户数据目录，不需要搬运或删除 AppData。

以后快捷方式固定指向根目录 `OpenClaw.exe`，不要直接指向 `versions` 中的具体版本。安装目录应位于当前用户可写位置；不要求安装器、管理员权限或常驻服务。

## 日常更新

托盘「检查更新…」仍是同一个入口。目录版只选择匹配的 `-directory.zip`，单文件便携版仍只选择 `.exe`，不会互相替换。默认预览通道能看到 Preview；仅稳定版通道不显示预览发布。

1. 在旧版正常运行时下载完整 ZIP，并校验 GitHub 发布的 SHA256SUMS。
2. 下载完成后询问是否重启。取消不退出、不切换版本。
3. 将包内更新引擎复制到临时目录启动，收到一次性 token 回执后才提交并退出客户端。
4. 助手确认提交及旧主进程已退出，再用锁定的同一文件流重新校验 ZIP，安全解压并逐项验证文件清单。
5. 新版本部署到独立目录，原子切换 `current.json`，保留旧版本。
6. 启动新版；本地壳加载并显示主窗口后回报健康状态。未确认或启动失败则恢复旧指针并启动旧版。

健康确认不等待 Gateway 在线或音乐接口，网络不可用不会被误判为本地启动失败。彻底退出后的日常启动只读小指针并启动现成版本，不重复解压、不全量计算运行时哈希。

## 目录协议 v1

```text
OpenClaw/
├─ OpenClaw.exe                 固定小启动器
├─ current.json                 {schema:1,version,previous?}
├─ versions/
│  ├─ 0.4.7/
│  │  ├─ OpenClaw Desktop.exe
│  │  ├─ resources/...
│  │  └─ update-manifest.json
│  └─ 之后的新版本/...
└─ .update/                     锁、健康回执和临时部署区
```

`update-manifest.json` 包含 schema、version 及所有版本文件的相对路径、长度和 SHA256，不包含它自己。发布 ZIP 根只有启动器、初始指针和一个完整版本目录。固定启动器不在正常更新时覆盖；更新引擎来自当前版本包内的 `src/directory-launcher.exe`，拷出到临时目录执行，因此更新引擎本身可随客户端升级。

`current.json` 仅允许安全版本名，不接受任意路径；拒绝链接、路径穿越、盘符/ADS、重复路径、越界解压及超限包。目录更新持有独占锁，旧进程未退出或版本指针已经变化时不得覆盖当前运行版本。不同构建不能复用同一个版本号。

旧版本不会在这一步自动删除，以免回退或诊断期间被清理。至少保留前一版，因此更新时需要足够空间存放下载包与新旧运行时。失败部署会与正常版本目录隔离，不覆盖任何已有版本。

## 当前阶段

这是“自动整包更新”，不是文件级增量。下一阶段才加入按文件哈希只下载变更文件，保留此目录协议。更新时仍需要解压一次，日常启动不再解压。

原有单文件便携 EXE 继续支持原位升级，但仍有便携自解压开销。目录版和便携版共用用户配置，不能同时启动两个独立实例。

## 验证边界

非 GUI 检查覆盖安装识别、ZIP/EXE 选择隔离、下载校验、取消不退出、token 握手、真实 Node/Electron Node 模式父进程退出、完整部署、ZIP/manifest 错误、穿越/重复路径拒绝、健康失败回退、无提交不更新等。新启动客户端使用原生无界面探针，不运行 Electron GUI。

用户本机仍需验收固定启动器、托盘更新提示、重启后的真实窗口和设置保留。回执表示本地窗口已显示，不表示 Gateway 已连接，也不是对之后所有运行时故障的自动修复。


## 构建约束

目录包必须使用 `scripts/create-directory-archive.ps1` 显式生成统一的正斜杠 ZIP 路径；Windows 默认压缩工具生成的路径曾被严格解析器拒绝，不能靠放宽路径校验解决。CI 先用小包预检生产者与原生解析器，再对实际最终 ZIP 调用随包原生 Extract/ValidateDistribution，仅解包校验，不启动 GUI。
