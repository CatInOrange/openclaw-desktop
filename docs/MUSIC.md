# 极简心动音乐播放器（v0.4.5）

## 使用

Windows 窗口按钮左侧常驻播放/暂停、喜欢、下一首及展开箭头。歌名不常驻，点箭头展开后显示歌名、歌手及登录状态。

第一次点击播放会打开网易云扫码面板；使用网易云音乐 App 扫码确认，再点播放。登录成功后在支持系统加密存储的机器上保存加密凭据，后续启动按需恢复，不自动发声。系统加密不可用时仅维持本次会话，绝不以明文降级保存 Cookie。面板支持退出登录和刷新二维码。

音乐进程和音频视图均由 Electron 壳承载。Control UI 只注入顶部布局让位样式，不暴露音乐桥接，不修改 Gateway 源码或配置。

## 连续播放规则

- 播放结束自动切换下一首；剩余歌曲少于五首时，提前补充心动推荐。
- 不设置三首、十首或固定总首数上限；推荐返回多少首也不作为停止信号。
- 按歌曲 ID 去重，优先选择近期未播放歌曲；连续三次补队列仍无新歌时，复用服务端心动推荐池，优先避开当前歌曲。不会暗中切换到私人 FM 或日推。
- 不可播、仅试听歌曲会跳过；单次切歌最多尝试八首。连续八次媒体失败会停止并提示，避免网络故障时无限快进。用户点击下一首可重新尝试。
- 音乐不属于会话：切换/刷新 Control UI、展开/收起面板、最小化、关闭到托盘不销毁音频实例。彻底退出客户端才停止。
- 手动下一首与自动下一首串行处理。旧歌曲迟到的 ended/error 不得再次跳过新歌曲；红心写入归属于操作时的歌曲，写入成功才改变显示。

## 当前限制

- 当前实测的是红心歌单种子的旧式心动/智能播放，不声称与网易云新版首页推荐完全等价。
- 使用第三方协议适配包 `@neteasecloudmusicapienhanced/api@4.41.1`，不是官方 SDK。当前采用实测成功的普通 MP3 播放接口，不使用解锁、换源或地域伪造；歌曲是否可播遵守账号和服务端权限。
- 这是新的客户端登录，与 Gateway 登录独立。验证机器的临时会话不打包进客户端，用户需在自己的电脑扫码。
- 默认音量由系统管理，不提供音量滑条、歌词、搜索或独立播放列表界面。

## 验证边界

非 GUI 自动测试覆盖多轮队列续补（40 次自动切歌）、有限推荐池回收、暂停恢复、快速连点、旧事件去重、红心失败保护、登录及过期、空歌单、全不可播、Worker 初始化、加密存储策略和 IPC 隔离。

真实账号已通过正式 Worker + Controller 连续取得 12 首正常权限 HTTPS 音频地址；早期独立探针已对三首 MP3 完整下载并用 ffmpeg 全量解码。未把这些接口验证冒充为真实 Electron 发声或 Windows GUI 验收。Windows CI 检查打包后的实际 Electron Node 运行时能加载音乐 Worker 和依赖并离线生成二维码。

用户本机验收：扫码 → 播放 → 暂停恢复 → 连点下一首 → 红心同步 → 自然播完自动续播（至少四首）→ 收起/切换会话/刷新/最小化/托盘不断播 → 退出重开可恢复登录、但不自动发声。并检查最窄窗口、缩放、全屏和浅色主题下控件无重叠。
