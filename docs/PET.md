# 桌宠预览版（v0.4.0）

托盘或应用菜单「显示桌宠」。右键角色 →「OpenClaw 工作状态」展开概览（不显示常驻状态标签），点击会话返回 Control UI。
可拖动角色；概览提供缩放、置顶和隐藏。主窗口收起不影响桌宠，退出应用一起结束。

工作动作：思考冒泡、忙碌点按、清点归档、等待授权时踱步、最后一轮结束庆祝、整轮失败叹气。多个 Agent 共用一个主动作，以数量与列表补充；取消不庆祝。断线或快照不完整用灰色待机并标明未知，不冒充空闲。

观察器复用 Control UI 已认证的 WebSocket，不读取或复制凭据，不启动第二份模型，不解析聊天文本。通过协议订阅、工具/生命周期事件和定期分页快照校准。该桥接对当前 Gateway 协议适配；不支持时显示未知，不降级猜测。授权权限不足或回放不完整时，状态卡明确提示授权提醒覆盖不完整，工作动作仍按可靠的活动快照显示；普通异步提问尚不映射等待。

素材来自 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 0.4.9，禁止商用，公开二创须署名。DSH 专属聊天、钱包、模型配置未移植。

## 本机验收（不在构建机进行 GUI 测试）

- 两个 Agent 同时运行：一个结束后另一个继续，计数与动作不清零。
- 工具调用、串并行工具返回、授权批准/拒绝/过期。
- 断线重连、运行中启动桌面壳，不能假空闲。
- 透明视频、透明区域穿透、拖动、缩放、多屏位置恢复。
- 主窗口隐藏后继续观察；从桌宠进入对应会话；退出不残留进程。

默认画框与上游一致为 462×260（16:9），旧版默认 190 自动迁移；手动缩放保留。已确认空闲时按动画结束轮换呼吸、玩魔方、三球抛接、摇摆舞；工作开始立即接管，断线/未知仅待机。播放器强制静音，左键单击播放随机回应动画并可重试失败播放，错误在展开卡片显示。

左键点击随机播放上游五套点击回应并做 Q 弹；连续点击没有另设双击行为，拖拽不触发点击。回应结束恢复当前工作/空闲动画。右键菜单含工作状态、走动开关、缩放、置顶和隐藏。角色始终保持原色。空闲走动首版使用上游螃蟹走路：按动画时间推进，首尾各停 2 秒，距离按 462 基准缩放；工作、点击、拖拽、展开状态卡、关闭走动开关均停止移动，并限制在当前屏幕工作区。尚未移植原版完整走位/物理系统。
