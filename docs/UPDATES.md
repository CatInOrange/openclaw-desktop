# 便携版升级（v0.4.1 起）

第一次手动下载 v0.4.1 或更高版本。此后从托盘「检查更新…」升级，不需要安装器或常驻服务，也不请求管理员权限。

- 仅主动检查，不后台自动下载。默认预览版通道（包括稳定版），可在托盘切换到仅稳定版。
- 检查 GitHub 公开 Releases，不依赖 Actions 账户或 GitHub Token；尚未发布的构建不会出现。每次正式提供更新必须增加 package.json/package-lock.json 的版本号并发布匹配标签、Windows EXE 与 SHA256SUMS。
- 显示更新说明 → 确认下载 → 托盘显示百分比，可取消 → 校验大小和 SHA256 → 再确认「重启并升级」。选择暂不升级会删除本次临时下载，不退出客户端。
- 只退出桌面客户端，不调用 Gateway 重启接口，不取消远程任务。未提交的编辑内容请先保存。
- 仅支持 Windows x64 便携 EXE。使用 electron-builder 的 PORTABLE_EXECUTABLE_FILE 定位外层 EXE，不能使用临时解包目录内的 process.execPath。原目录必须可写。
- 更新助手是随包编译的小型无界面 EXE，复制到临时目录运行，不常驻、不依赖 PowerShell。先再次校验下载文件，确认就绪后客户端才退出；等待客户端与外层便携启动器释放文件，再原子替换。
- 在原路径保留旧版 `<原文件名>.previous.exe`。校验失败不退出、不替换；替换失败保留旧版并尝试重启；新 EXE 进程无法启动时尝试自动回退，并记录结果。不能自动检测所有“进程启动后 UI 空白/程序逻辑错误”，此类问题从备份手动恢复，不承诺 GUI 健康检测。
- 手动回退：从托盘彻底退出客户端，将当前 EXE 改名留存，再将 `.previous.exe` 移回原名称并运行。下一次升级会覆盖上一份备份。
- 连接地址、Control UI 持久登录状态、外观和桌宠设置存放于原有 userData，不随 EXE 替换。更新结果记录于 userData/update-result.json，下一次启动读取后留作 update-result.json.last。
- 网络使用 Electron net.fetch/系统代理；失败提示可重试，不降低 TLS 校验，不使用随机镜像。
- 官方便携包当前未提供发行商 Authenticode 签名。原位升级会换成官方发布的原始 EXE，不会自动沿用用户之前对旧 EXE 做的个人签名；需要时可重新运行个人签名工具。

Windows CI 用临时控制台程序验证真实替换、校验拒绝和启动失败回退，不启动 GUI；实际托盘操作、重启后的窗口和本机权限行为由用户验收。

## v0.4.4 更新助手启动与握手修正

旧版只等助手 5 秒，且助手先重复校验大 EXE 才回报就绪，缺少启动错误日志。这是已确认的时序缺陷，但不能仅据“未就绪”弹窗断定每台机器的确切原因。

新版将启动确认和升级提交分开：助手先写一次性 token 回执，客户端最多等待 30 秒；收到正确回执才提交升级并退出。助手必须收到提交且客户端退出后，才重新校验文件并替换。迟到、取消、错误回执不能触发更新。更新助手输出保存在 userData/update-result.json.helper.log，启动失败结果写入 update-result.json。Windows CI 新增真正从 Node 启动独立更新助手 的端到端非 GUI 验证，包括中文、空格、括号路径和校验失败保留旧版。

如果旧客户端仍因其内置助手问题无法升级，需要手动下载 v0.4.4 便携包并从托盘彻底退出旧版后运行；新包不能改变旧进程已经携带的升级逻辑。现有设置仍保留。

后续真实 Windows 对照测试确认：Windows PowerShell 使用 detached:true 时在脚本执行前就退出，四组“脚本/编码命令 × 输入管道”均无回执；相同参数去掉 detached 后四组均有回执。最终生产助手改为独立的无界面 .NET EXE，不再使用 PowerShell。CI 验证真正的 Node 和 Electron（ELECTRON_RUN_AS_NODE，无 GUI）父进程退出后，助手仍能完成替换与保留旧版。v0.4.3 标签构建未通过此测试，未发布安装包。

独立助手使用 Windows 自带 .NET Framework 编译为 WinExe（不创建任何界面/控制台），不要求安装器、不修改执行策略、不运行常驻服务；保留启动、提交、父进程退出、校验、替换和启动结果的日志。


## v0.4.7 免安装目录版

目录版与单文件版共用托盘更新入口，但分别只选择 `-directory.zip` 和 `.exe`。目录版采用固定启动器和独立版本目录，下载校验后询问重启；旧进程退出后助手安全部署、切换指针，等待本地窗口健康确认，失败回退。详见 [目录更新协议](DIRECTORY-UPDATES.md)。v0.4.6 的旧 raw 目录首次需手动解压新目录包，此后可自动整包更新。固定入口是根目录 `OpenClaw.exe`，不是版本目录内的 `OpenClaw Desktop.exe`。
