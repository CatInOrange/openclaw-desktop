# 便携版升级（v0.4.1 起）

第一次手动下载 v0.4.1 或更高版本。此后从托盘「检查更新…」升级，不需要安装器或常驻服务，也不请求管理员权限。

- 仅主动检查，不后台自动下载。默认预览版通道（包括稳定版），可在托盘切换到仅稳定版。
- 检查 GitHub 公开 Releases，不依赖 Actions 账户或 GitHub Token；尚未发布的构建不会出现。每次正式提供更新必须增加 package.json/package-lock.json 的版本号并发布匹配标签、Windows EXE 与 SHA256SUMS。
- 显示更新说明 → 确认下载 → 托盘显示百分比，可取消 → 校验大小和 SHA256 → 再确认「重启并升级」。选择暂不升级会删除本次临时下载，不退出客户端。
- 只退出桌面客户端，不调用 Gateway 重启接口，不取消远程任务。未提交的编辑内容请先保存。
- 仅支持 Windows x64 便携 EXE。使用 electron-builder 的 PORTABLE_EXECUTABLE_FILE 定位外层 EXE，不能使用临时解包目录内的 process.execPath。原目录必须可写。
- 更新助手是复制到临时目录的 PowerShell 脚本，不常驻。先再次校验下载文件，确认就绪后客户端才退出；等待客户端与外层便携启动器释放文件，再原子替换。
- 在原路径保留旧版 `<原文件名>.previous.exe`。校验失败不退出、不替换；替换失败保留旧版并尝试重启；新 EXE 进程无法启动时尝试自动回退，并记录结果。不能自动检测所有“进程启动后 UI 空白/程序逻辑错误”，此类问题从备份手动恢复，不承诺 GUI 健康检测。
- 手动回退：从托盘彻底退出客户端，将当前 EXE 改名留存，再将 `.previous.exe` 移回原名称并运行。下一次升级会覆盖上一份备份。
- 连接地址、Control UI 持久登录状态、外观和桌宠设置存放于原有 userData，不随 EXE 替换。更新结果记录于 userData/update-result.json，下一次启动读取后留作 update-result.json.last。
- 网络使用 Electron net.fetch/系统代理；失败提示可重试，不降低 TLS 校验，不使用随机镜像。
- 官方便携包当前未提供发行商 Authenticode 签名。原位升级会换成官方发布的原始 EXE，不会自动沿用用户之前对旧 EXE 做的个人签名；需要时可重新运行个人签名工具。

Windows CI 用临时控制台程序验证真实替换、校验拒绝和启动失败回退，不启动 GUI；实际托盘操作、重启后的窗口和本机权限行为由用户验收。
